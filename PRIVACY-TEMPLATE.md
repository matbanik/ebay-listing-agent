# Privacy policy template (for your eBay RuName)

eBay requires a Privacy Policy URL when you create a RuName (EBAY-API-SETUP.md step 5). This template describes what this pipeline does when one seller runs it on their own account. Replace the `<...>` parts, delete anything that isn't true for your setup, and publish it somewhere with a stable HTTPS URL (a GitHub Gist, or a page in a public repository).

This is a starting point, not legal advice.

---

## Privacy policy for <application name>

Last updated: <date>

<application name> is a private tool used by <your name or business> to create and manage listings on <your name or business>'s own eBay seller account. It is not offered to other eBay users, and no one else signs in to it.

**What it accesses.** With the seller's consent, given through eBay's sign-in page, the tool reads and writes the seller's own inventory items, offers, listings, business policies and inventory locations through eBay's APIs. It reads public active-listing data and category data from eBay.

**What it stores.** The tool keeps files on the seller's own computer: product photos, listing text, prices, and the eBay offer and listing IDs of the seller's own listings. Access credentials are stored in a local file that is not shared. It does not collect or store data about buyers or other eBay users.

**Deletion.** The seller can delete the local files at any time. To withdraw the tool's access, <describe how: for example, delete the credentials file and change the application's Cert ID>.
